## Overview

Audiobook Downloader Utility is built for Windows users who want a structured way to download and manage audiobook files. Multiple items can be placed in a queue, processed in parallel, retried after temporary failures, and resumed when an interrupted transfer can continue.

After downloading, the utility can prepare files for playback by recognizing chapters, adding labels, tagging metadata, and attaching cover artwork. Audiobooks can be exported as M4B, MP3, or FLAC. The portable executable, dark and light themes, and configurable bandwidth limits support both occasional use and larger personal libraries.

## How to Use

The usual download process is:

1. Open the application in Windows.
2. Add one or more audiobook sources or entries to the queue.
3. Pick M4B, MP3, or FLAC as the output format.
4. Choose the folder where the audiobook library will be stored.
5. Check duplicate notices and the current queue state.
6. Begin processing the queue.
7. Allow the utility to retry temporary failures and resume interrupted items.
8. Inspect the resulting chapter names, metadata, cover art, and file layout.

Parallel processing is useful for larger queues because several items can be handled together. When network usage needs to stay below the full available connection, configure bandwidth throttling.
